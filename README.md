## Skills

Skills are folders containing instructions and, when needed, scripts,
references, or other resources that help an AI assistant carry out a
specific kind of task.

A skill can capture a repeatable workflow, provide relevant context,
or guide an assistant through a specialized activity.

## About This Repository

This repository is a portfolio for collecting and sharing reusable AI
skills and workflows. It reflects my interest in AI-assisted work,
automation, practical software development, and context engineering.

The portfolio is intended to develop over time as skills are created,
tested, and improved.

> **Note:** For information about the Agent Skills standard, see [agentskills.io](http://agentskills.io).

### Disclaimer

These skills and workflows are shared for educational and
experimental purposes. AI-generated output can be inaccurate or
incomplete, so review results before relying on them.

Review any instructions, scripts, and requested permissions before
using a skill, especially when it interacts with external services,
personal information, or your files.
