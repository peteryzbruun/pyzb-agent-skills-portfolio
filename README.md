## About This Repository

This repository is a portfolio for collecting and sharing reusable AI skills and workflows. It reflects my interest in AI-assisted work, automation, practical software development, and context engineering.

The portfolio is intended to develop over time as skills are created, tested, and improved.

> **Note:** For information about the Agent Skills standard, see [agentskills.io](https://agentskills.io).

## Skills

Skills are folders containing instructions and, when needed, scripts, references, or other resources that help an AI assistant carry out a specific kind of task.

A skill can capture a repeatable workflow, provide relevant context, or guide an assistant through a specialized activity.

The [skills](./skills/) folder is ready for skills to be added; it does not yet contain any published skill packages.

> **Note:** The skills in this repository are primarily built for OpenAI, Codex, and ChatGPT, but can also be used with other AI agents. Compatibility and installation steps may vary by agent.

## How to Use

1. Browse the [skills folder](./skills/) as skills are added.
2. Read a skill's instructions and review any scripts, resources, and permissions before using it.
3. Follow your AI agent's instructions for installing or using skills. Check each skill's documentation for any additional requirements.

## Disclaimer

These skills and workflows are shared for educational and experimental purposes. AI-generated output can be inaccurate or incomplete, so review results before relying on them.

Review any instructions, scripts, and requested permissions before using a skill, especially when it interacts with external services, personal information, or your files.
